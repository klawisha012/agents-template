# Triage Labels

Стандартные метки; строка метки равна имени роли.

| Метка | Смысл |
| --- | --- |
| `needs-triage` | Требует разбора |
| `needs-info` | Ждёт информации от автора |
| `ready-for-agent` | Полностью описан, можно брать (и распределять) |
| `ready-for-human` | Требует работы человека |
| `wontfix` | Не будет сделано |
